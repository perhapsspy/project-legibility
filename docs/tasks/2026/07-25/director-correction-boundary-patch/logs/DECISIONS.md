# 결정 기록

**2026-07-25**

- **배경:** 정본 변경은 기존 디렉터 역할 안의 사용자 교정 전달과 영향 작업 중단 계약을 보강하며 제품 구성 역할은 바꾸지 않는다.
- **결정:** `0.6.1` 패치에서 디렉터 출처와 생성 묶음만 갱신하고, 명시적 디렉터 세션의 교정은 선택하며 일반 작업의 교정은 선택하지 않는 회귀를 추가한다.
- **이유:** 변경된 감독 동작을 배포하면서 기존의 명시적 디렉터 지정 경계를 그대로 증명할 수 있다.
- **영향:** `ui-design-rigor`를 포함한 다른 스킬의 정본·역할·호출 회귀는 유지된다.
