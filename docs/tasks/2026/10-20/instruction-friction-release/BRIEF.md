# 과검증·작업 중단 지침 교정

## 목적과 범위

사용자가 승인한 공통 지침 두 항목과 structure-first 검증·tighten-docs 이관 문구를 한영 정본에 반영하고 게시·설치한다. 기존 미커밋 변경은 보존하며 이번 커밋에서 제외한다.

## 현재 상태

다섯 원본 파일 수정 완료. 원본 검증과 범위별 커밋·푸시 후 Project Legibility patch release, publisher pin, Mac 설치 확인을 진행한다. dot은 지원 실행 경로를 확인하고 Windows는 수동 반영 상태로 구분한다.
