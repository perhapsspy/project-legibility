# Decisions

**2026-07-28**

- **Background:** `CONTRIBUTING*`가 owner, 개발, version, release와 rollback을 한 문서에서 다시 연결한다.
- **Decision:** 필요한 정책을 기존 PRODUCT와 release runbook에 합치고 `CONTRIBUTING*`를 제거한다.
- **Why:** 각 주제의 현재 정본이 이미 존재하며 별도 라우터가 독자의 다음 행동을 줄이지 않는다.
- **Impact:** README, PRODUCT, ARCHITECTURE와 runbook이 각각 하나의 역할을 직접 소유한다.
