# 진행 관측과 작업 비용 비교 개선

진행 관측을 완료·새 신호·다음 판단에 맞추고, 동등하게 검증된 결과를 기준으로 고유 호출과 재작업을 비교한다. 정본 `agent-cost-efficiency`의 한·영 진입 문서를 수정하고 공개 `main`의 `4c2c7639dcda4b2008276a2aa71b33d4d19ce76d`로 조립했다.

현재 원격 main에 이미 포함된 방향 검토 범위 변경에 맞춰 Project Legibility `0.19.0`을 준비했다. 게시 런북에 따라 릴리스와 양쪽 marketplace를 확인한 뒤, 공개 archive에서 배포된 정본과 bundle을 대조한다.

짧은 작업, 이벤트 기반 관측과 시간 제약, 장기 작업의 독립 QA와 고유 호출 집계를 검토했다. 이 검토는 선택 기준을 확인하며 실제 비용 감소의 실측은 포함하지 않는다.
